# JOY_REPORT — устойчивое чтение джойстиков (ветка joy-robust)

> **19.10.2026: только джойстик «П».** По решению владельца («джойстик везде — «П»»)
> `V_JOY_RAW` больше не читает порт 0x0E (джойстик «С»): остался опрос ППИ2 (порт 06h)
> с тем же фильтром мусора и базой `v_joy_base_p`. Ячейка `v_joy_base_s` осталась на
> месте и не используется (раскладка данных адаптера та же). `adapter_probe.py`: вместо
> проверок порта 0x0E — «все 256 состояний порта 06h» и «порт 0x0E не читается: все 256
> значений → ничего не нажато»; итого 42 из 42. В эмуляторе (vector06js, порт 06h по
> RTL MiSTer): «П» вправо двигает героя, мусор 00 на 0x0E не меняет ни одной точки кадра.
> Ниже — отчёт о ветке joy-robust как она была (два порта).

### ППИ2 в Spirits

Порты `04`/`05`/`06` до правки **нигде не использовались**: звук — ВИ53 (`08`–`0B`), клавиатура/видеозащёлки — ППИ1 (`00`–`03`), covox/ROM-диск в порте нет. Чтение Джойстик-П через ППИ2 безопасно.

## Адреса и размеры адаптера

| | до (main `5cc7b10`) | после (joy-robust) |
|--|---------------------|---------------------|
| `V_JOY_RD` | `4D69` | `4D6A` |
| `V_JOY_RAW` | — | `4D85` |
| `vj_port` | — | `4DA2` |
| `V_CODE_END` | `4D83` | `4DBB` |
| `v_joy_base_s/p` | — | `4DDE` / `4DDF` |
| `v_msxrow` | `4DC0` | `4DE0` |
| `V_END` | `4DD8` | `4DF8` |
| `adapter.bin` | 984 б (`4A00..4DD7`) | 1016 б (`4A00..4DF7`) |
| связка | `4DE8..4E99` (178 б) | `4DF8..4EA9` (178 б) |
| таблица SFX | `4EAA..4F21` | без изменений |
| модуль читов | `4F3E..` | без изменений, не пересекается |

Адаптер упирается в связку (`V_END == GLUE_ORG == 4DF8`), связка упирается в SFX (`4EA9+1 == 4EAA`). До читов (`4F3E`) — дырка `4EAA..4F3D` (SFX + `V_VAR2`), код адаптера туда не заходит.

Базы лежат в записываемой RAM адаптера и **не** входят в `V_SND_VARS` / `V_KBD_INIT` — между титрами и игрой не затираются.

## Проверено

- `check_i8080` чисто; `adapter_probe` — все проверки выше (в т.ч. мусор `00`/`0E`/`36`, оба порта, огонь с первого опроса, `bc/de/hl`, такты).
- ППИ2 свободен (аудит исходников порта).
- Адаптер не залезает на SFX `4EAA` и читы `4F3E`.
- Полная i8080-сборка порта собирается.
- `~/projects/spirits-v06c` и его worktree не трогались.

## Не проверено, предположения

- **Эмуляторный прогон титров** (`emu80_run.sh` / `vector06js`): в этом репозитории нет `tools/emu80_run.sh`; скрипты `*_v06js.js` из docs живут в исследовательском дереве, сюда не входили. Предположение: при `0Eh=0Eh` или `36h` `T_KEY` через `V_JOY_RAW` вернёт Z (титр не проскочит); огонь на `0Eh`/`06h` после базы FF даст NZ — по покрытию `adapter_probe`, не по кадрам эмулятора.
- **Железо** (Вектор Турбо+, настоящий Джойстик-П): не гонялось.
- Постоянный перепрограммирование ППИ2 на каждом опросе (как в эталоне Tony) — намеренно; однократная инициализация в `V_KBD_INIT` сэкономила бы такты, но не размер адаптера относительно связки.
